# Jobs To Be Done Canvas

A single-page exercise where participants complete mad-lib style cards to uncover the job a product does in their customers' lives.

Each card reads: **As a** (self-identifier) **I want to** (unmet need / frustration) **I need** (solution / tool) **in order to** (goal / objective) **so that** (desired outcome / emotion), plus an optional context / barrier.

Click a coloured blank to read what it means and type an answer. **See examples** shows completed cards, **Submit** saves the card and clears it for another, and **Reset** clears the card in progress. Saved cards can be edited, deleted, copied or emailed.

No libraries, no build step, no server. Nothing is sent automatically.

## Publish on GitHub Pages
1. Upload `index.html` and `README.md` to the root of a repository.
2. **Settings → Pages**, Source: **Deploy from a branch**, branch **main**, folder **/ (root)**, Save.
3. Your page goes live at `https://<your-username>.github.io/<repo-name>/` after a minute or two.

If you want this on the same site as another page, put it in its own repo or in a subfolder with its own `index.html`.

## Customise
Edit the marked block near the bottom of `index.html`: `SEND_TO` (email address), `FIELDS` (labels and explanation text, currently placeholders) and `EXAMPLES`.
